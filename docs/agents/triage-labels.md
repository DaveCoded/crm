# Triage labels

| Canonical state   | Linear label      |
| ----------------- | ----------------- |
| `needs-triage`    | `needs-triage`    |
| `needs-info`      | `needs-info`      |
| `ready-for-agent` | `ready-for-agent` |
| `ready-for-human` | `ready-for-human` |
| `wontfix`         | `wontfix`         |

For category roles, use one existing Linear label: `Bug` for bugs, `Feature` for new capabilities, or `Improvement` for changes to existing capabilities. Keep exactly one state label and one category label on a triaged issue. Status (Backlog, Todo, In Progress, Done, etc.) tracks progress separately from the triage label.
